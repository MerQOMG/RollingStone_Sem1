## 执行agent必须遵守的补充说明

你接到的是实施任务。当前聊天不用再复述一份计划后停下；先检查现场，继而持续执行。

### 开始顺序

1. 查看实际cwd、AGENTS.md、Git分支/status/log。不要先拉取覆盖用户文件。制定计划时HEAD已是078205a，且RollingStone.sln有用户修改；执行时可能再次变化。
2. 完整阅读 `IMPLEMENTATION_PLAN.md`。用户已确认两个授权：允许新三维文件与Jolt，允许球面顶点联合约束采样。对本计划职责范围内的普通实现不重复征求许可。
3. 若已有 `docs/3d/PROGRESS.md`，先读并核实，接续最早未完成阶段。否则创建进度文件，记录起始HEAD及用户改动清单。
4. 在当前适用checkout继续，必要时创建 `codex/rollingstone-3d` 分支。不要创建新聊天或子agent，不擅自创建重复工作区。
5. 执行P0：二维基线验证、现有MSVC/CMake确认、Jolt v5.3.0标签解析并锁定到SHA、最小构建。不要安装新编译器或默认改用MinGW。

### 核心要求

- 三角面组成完整凸刚体；k是顶点数，r是生成球半径，V是实体体积。
- 每个顶点在球面上，凸包顶点恰为k；体积与惯量要独立验证。不要通过缩放整个实体改变r来凑V。
- 按计划的首版支持域实施。支持上限不是数学极值；不得把“超出当前支持范围”说成“数学无解”。
- 实现参考凸包、受扰动球面顶点、立体投影收缩和体积括区求根。算法不是独立均匀球面取样，要记录分布版本。
- 运动与绘制分离，唯一Trial::step，固定物理步长；预览不能改变随机数顺序与结果。
- 保留二维版；三维使用独立Win32/OpenGL观察窗口及Jolt物理，三维弹性网/破碎不属于本期。
- 三维统计按质心线段穿越体素、单次去重；失败/取消/超时不混入完整概率，输出能重放形状与地形。

### 执行节奏

- 依次完成P0-P6；阶段结束更新PROGRESS及证据，不做阶段提交，不等待用户说“继续”。
- 合理的内部实现选择由你处理。遇到失败先最小复现、定位、修复、重跑相关验证；已经通过且未受影响的测试不反复空转。
- 不得通过降低测试阈值、减少实际k、改变r/V、隐藏失败或硬编码演示结果来宣布通过。
- 用户后来发来的问题先简短回答，再继续原目标，除非明确暂停/取消。
- 若用户停止GUI操作，遵守停止指令，并将未完成的实际交互验证明确记录；后台测试不能被冒称为GUI测试。
- 如果必须安装新编译器、引入第二个大型依赖、改变模型/验收合同，或遇到权限/认证阻塞，说明具体原因并请求决定。先做其他不依赖该决定的工作。Goal状态按宿主工具规定管理，不为了结束而宣称complete。

逐项核对计划第7节G/D/S测试及第10节清单。最终报告必须区分真实运行证据与未验证假设，给出一键命令、CSV路径、采样/物理局限、测试结果与提交号。
