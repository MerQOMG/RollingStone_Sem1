## 2. 技术路线与三角建模口径

1. 凸多面体是一个完整实心刚体。先求凸包，再将凸包各面三角化；三角面不能各自建立为动态刚体。
2. k 表示凸包顶点数，不表示面数。闭合凸面三角化且不新增顶点时，检查 `E=3k-6`、`F=2k-4`、欧拉示性数2；共面多边形面也要正确三角化，不重复计算面积/体积。
3. 地形是静态连续三角网格，共享顶点和邻边；相邻同平面三角形的对角线不应变成有物理凸起的边。
4. 体积、质心、惯性张量根据封闭实体积分。质量 `m=rho*V`，默认 rho=2600 kg/m³，取消二维版的固定1m厚度假设。
5. 坐标统一：x沿原下坡方向，y横向，z向上；重力 `(0,0,-9.81)`。Jolt的物理坐标不强制Y向上；需显式设置重力，并将raylib相机up设为Z方向（俯视另取正交up）。显示、射线、CSV和物理均按这一约定转换。

## 4. 几何输入域与可实现的生成算法

### 4.1 首版支持域

输入 `k_min, k_max, r, V`。默认 `4, 8, 2m, 3m³`。

- `4 <= k_min <= k_max <= 30`。
- `0.2 <= r <= 10` 米。
- 首版数值支持下限 `V/r³ >= 0.02`，不宣称更小体积在数学上不可能。
- 首版体积上限采用可构造参考形状，而非未经证明的真正极值：

  `B4(r) = 8*r³/(9*sqrt(3))`（正四面体）；

  `Bk(r) = (k-2)*r³*sin(2*pi/(k-2))/3`，k>=5（球面两极+赤道正(k-2)边形构成双锥）。

- 要求 `V <= 0.90 * min(Bk(r), k in [k_min,k_max])`。这明确是**首版支持上限**，不是“该k的数学最大体积”；GUI必须这样标注。
- 球心不要求在凸包内部；r是指定生成球半径，不保证是最小包围球半径，也不是质心到最远顶点距离。

必须支持输入 `10 20 7 20`。不得把它改成20m²、修改r、减少抽到的k或用球体替代。

薄体、短边和近共面点是首要数值风险；`V/r³`不能唯一确定厚度/长宽比，r也不保证是最小包围球半径。每个实际样本记录最小顶点间距、最小三角面积、质心到面最小距离 `d_in`、顶点最大间距D，以及 `D/(2*d_in)`。最后一项是基于质心内切球的保守细长度指标，不冒称求得了任意方向的最小厚度。

候选数值质量门槛：规范几何须非退化且 `d_in >= 32*tau*r`，tau定义见4.3；再以引擎实测的k、几何/质量误差决定是否接受。未满足者属于同k构造重试，并记录拒绝原因和采样分布版本。该门槛不能偷偷缩小上述用户输入范围；P1若在既定范围无法达到通过要求，应报告支持域尚未实现，不能把用户case删除或宣称数学无解。它是待验证的工程门槛，不是已有通过率保证。

### 4.2 联合约束采样：参考凸包 + 球面连续变形 + 体积求根

下列是待实现和验证的构造方案，不是已经验证的现成程序。

1. 从[k_min,k_max]中均匀抽取整数k，只抽一次；同一试验后续重试都保留这个k。
2. 构造上述参考k顶点球面形状，进行随机切向角扰动并归一化回单位球。逐步缩小扰动幅度，直到参考凸包体积高于目标；0.90容量限制提供构造余量。
3. 随机选择投影轴n，避开所有顶点的反极点。选取正交基(e1,e2,n)，所有单位顶点q_i满足 `1+q_i·n > 0.01`；若候选轴不好就更换轴，最多128次后报告具体失败。
4. 立体投影：`u_i=(q_i·e1,q_i·e2)/(1+q_i·n)`。对全部顶点联合缩放平面投影坐标 `u_i(t)=t*u_i`，t∈[0,1]。
5. 反投影：`q_i(t)=[2t*u_x*e1 + 2t*u_y*e2 + (1-t²|u|²)*n]/(1+t²|u|²)`，最后乘r。此处变化的是角度；没有缩放物理球半径。
6. t=1是参考凸包；t趋于0时所有点趋近n，体积趋于0。凸包体积连续，因此存在中间参数达到目标V。不要宣称全区间单调；用保持异号端点的二分括区求根，不使用未经证明的单调反函数。
7. t=0端点的体积直接按理论极限记为0，不把退化端点送进凸包库。其他t的凸包失败不能被当作“体积为0”，应按数值错误处理。最多80次求根，随后做独立几何检查。
8. 加随机整体旋转；重新验证全部约束。若出现近重复点、不可用的惯量或引擎丢顶点，同一k最多64次更换扰动/投影轴；失败需保留seed、k、r、V及诊断，不能悄悄重抽k或删掉失败样本。

该分布是受约束的形状族，不是所有定体积凸多面体的均匀分布。把 `sampler_version`、参数、试验seed和实际顶点写进结果，以便将来比较采样偏差。

### 4.3 几何与碰撞表示双重校验

规范几何使用double：

- 每个顶点距原球心的半径误差 <= `1e-8*r`。
- 实际体积误差 <= `max(1e-12*r³, 1e-6*V)`。
- 凸包顶点数恰为k；每条无向边恰有两面，方向一致，闭合、凸、无零面积三角形。
- 质心在实体内，惯性张量对称正定。
- 禁止面绕向错误导致正负体积互相抵消；四面体积分参考点优先取实体内部，减少消减误差。

Jolt适配层采用以下明确流程：

1. 凸包拓扑计算使用归一化坐标；最终碰撞形状用 `q_i=(p_i-c_double)/r` 构造，并通过均匀ScaledShape还原尺度r。这是坐标单位转换，不是通过改r凑V。质量、质心、惯量最终都在还原后的米制形状上比较。
2. 对每组归一化输入，取 `tau=max(1e-6, 3*FLT_EPSILON*(max|qx|+max|qy|+max|qz|))`；明确向Builder及 `mHullTolerance` 传入对应容差并记录实际值。v5.3.0内部还含浮点共面及最小三角面积判据；不能认为将inTolerance写为0即可保留任意近邻点。独立double拓扑也不能替代引擎最终float形状检查。
3. **强制 `mMaxConvexRadius=0`**，检查创建成功并读回实际凸半径为0；源码允许0，但不保证退化输入可构建。这样约束实际接触外形，不是因为任意非零凸半径必然改变GetVolume。引擎可能内缩支撑形状后再补半径，质量属性与圆角碰撞表示必须分别检查。
4. 读回实际顶点数恰为k，按几何位置匹配而非索引匹配；还原世界单位/质心约定后比较外形与质量属性。引擎体积/质量相对偏差 <= `1e-4`，质心偏差 <= `1e-5*r`，惯性张量相对Frobenius范数偏差 <= `1e-3`；超限即构造失败，不能只检查传入数据。

P0a先做显式四面体/立方体的零圆角创建与读回；P1先完成G1中的1100个用户case样本（计入5000总数），输出首尝试成功率、重试分布、最终成功率、d_in/细长度和误差，再继续扩大覆盖。接触尺度设置见5.2，不能沿用0.02m默认穿透容限后直接宣称毫米级验证通过。

## 5. 三维地形与物理定义

### 5.1 地形

首版默认明确采用 `rollingstone.cpp::buildTerrain(TerrainSettings)` 的参数化坡面，不采用HillSlope无参构造中的13点教师折线；保留原函数参数含义、公式与米制单位，不混拼两套控制点，不include整份二维main文件。

默认参数为 `H=55.6m, steepDeg=40, benchStart=25m, benchLength=15m, benchDeg=7, toeLength=20m`。按现有公式产生控制点约为 `(0,55.6),(25,34.62250922),(40,32.78074081),(79.06656562,0),(99.06656562,0)`。`x_foot`是主坡与坡脚平台交点79.06656562；`x_end`是网格最下游端点99.06656562（包含20m平台），不是硬编码120。执行时由实际控制点求值，文中小数仅作核对。

首个场景为 `h(x,y)=h0(x)`，横向总宽度40m，即y∈[-20,20]。再实现：

- 横坡：`h=h0(x)+tan(beta)*y`，beta默认0度，验证场景5度。
- 沟槽：`h=h0(x)+A*(y/w)^2`，w为半宽，验证场景A=2m。

网格名义步长1m：x网格由规则格线、所有控制点横坐标及末端点的并集排序去重组成，允许非均匀最后一格及折点附近单元；y同样保留精确边界。每个四边形固定分为两个三角形；接入静态MeshShape，处理共面内部边。测试插入11.25m等非整数折点，不因它不在整米格线上丢弃。默认无悬挑、洞穴或动态地形。P0b的80m宽解析测试地形是独立显示负载，不是本节40m宽的物理默认场景。

明确提供世界坐标地形顶点和三角面CSV；观察模式可切换面/线框，显示坡脚统计区和收集截面。

### 5.2 刚体

- 采用完整三维平动和转动，姿态四元数，质心位置与生成球心区分。
- 初始化按多面体最低支撑位置放到地面上方，检测初始穿透；不能使用“质心高度=地面+r”。
- 默认密度2600kg/m³、地面接触对摩擦0.45、恢复系数0.45、空气密度1.225kg/m³、Cd=1.0、c_rr=0.02。初始自旋三轴默认0；默认释放x=10m、y=0、支撑高度上方间隙0.05m、初速度0，用户case配置采用x=20m留出更大边界余量。这些是示例输入，不是工程材料标定结果。
- 逻辑步长dt=0.002s，每步调用 `PhysicsSystem::Update(dt,4,...)`；第二参数是碰撞子步数inCollisionSteps，不是求解器迭代次数，内部时间间隔初始为0.0005s。D6改变dt时固定子步数4和求解器设置，因此内部间隔随dt一起减半。改变渲染速度只改变现实时间内推进的固定步数量。
- μ/e明确表示落石与相应静态表面的接触对值：地面采用该试验抽到的值，挡板采用其配置值。使用 `SetCombineFriction/SetCombineRestitution` 回调按对象/子形状材质返回目标值；不依赖默认的摩擦几何平均、恢复系数取较大值规则。记录每一类实际接触对设置并做独立碰撞测试。
- 空气阻力采用 `F=-0.5*rho_air*Cd*A_proj*|v|*v`；首版 `A_proj=pi*r²` 为明确记录的等效面积近似，不冒充真实姿态相关迎风面积。
- 三维滚动阻力不能直接沿用二维标量omega公式。首版采用明确的现象学模型：存在地面接触时取平均接触法线n，`omega_t=omega-(omega·n)n`；对omega_t施加大小为`c_rr*m*g*r`、反向的力矩。每步按惯性张量限制耗散冲量，保证不反转该转动分量、不增加动能；离地时此项为0。该模型按重量定标，并不声称使用真实冲击法向力，也不包含绕法线扭转阻力；把这些近似写进配置说明和结果。测试c_rr=0无额外耗散，c_rr>0时总转动能不被该项增加。
- 接触配置以米制实际形状为准：`slop=min(1e-3m,1e-4*r,0.01*d_in)`，设置 `mPenetrationSlop=slop`；`mMinVelocityForRestitution=0.15m/s`。这是首版待验证设置，保持D3/D5原阈值；静止漂移不等于穿透量，不能由slop直接断言测试通过。
- 高速/薄体采用 `MotionQuality::LinearCast`，初始 `mLinearCastThreshold=0.25`；`mLinearCastMaxPenetration=min(0.02, p_limit/(4*d_engine))`，其中d_engine为米制形状读回的正内半径，`p_limit=max(0.002m,0.002*r)`。记录其他接触/求解器设置，在MeshShape、挡板及旋转薄体上实测。LinearCast不能被当作对任意高速转动的无穿透保证；仍需第D5/D6测试及必要的固定子步细化。

一批地形固定。初始x/y、初速度、摩擦、恢复系数、Cd、c_rr支持固定值或有限均匀区间；两端相同表示固定。r、V、k范围在批内固定，每次重新抽形状。不得继承当前二维批量中写死的释放位置和正态分布却不告知用户。

终止原因必须区分：稳定静止、越过下游边界、越过上游边界、离开横向边界、达到时间上限、几何失败、数值失败、用户取消。质心越过x_min/x_end/y边界时按吸收边界结束，先裁剪统计最后一段轨迹；域外未来运动不在本批范围。静止采用速度<0.05m/s、角速度<0.05rad/s且持续2s；默认模拟时限60s。时间上限是截断状态，不当作正常停止。

### 5.3 首版刚性挡板

挡板为有厚度的静态长方体；配置中心世界坐标、宽/高/厚度、绕z轴方位角、摩擦、恢复系数及启用标志。默认竖直、宽沿横坡方向、厚度沿下坡方向；三个尺寸必须为正。显示网格与碰撞形状共用同一尺寸和变换，配置及结果保存这些实际值。首版只支持一块挡板，在空闲状态通过参数输入放置，不承诺任意空间姿态拖拽。

默认禁用，宽10m、高5m、厚0.2m、方位角0度，中心x=x_end-10、y=0；启用时底面按覆盖区域的最高地形高度放置（接地示例，不声称完全封住起伏地形），中心z再加高度一半。μ/e默认各0.45，用户修改中心z后按实际位置校验并保存。挡板BoxShape同样显式用零凸半径，与显示的长方体棱角保持一致。

对挡板增加正撞、偏心撞击、越顶、绕侧边及禁用对照测试：有限尺寸应允许从边缘外通过，不能退化为无限平面。此处模拟刚性接触，结果中的反弹或能量损失不得标成弹性网变形。

## 6. 三维路线统计、展示和输出

### 6.1 统计区

默认统计区：`x∈[x_end-40,x_end]`（截断到有效地形范围）、整个配置y范围、`z∈[z_ref,z_ref+10]`。保留已选的固定坡脚高度口径，默认 `height_reference=toe_center`、`z_ref=h(x_end,0)`；它不是每个位置的离地高度。

同时提供显式可选项 `toe_min`：z_ref取末端网格边界上最小高程。配置和manifest记录模式、实际z_ref及统计盒。横坡β=5°、y∈[-20,20]时，中心基准会排除约-1.75m处部分低位路线，这是统计域定义的后果；GUI显示统计盒与该提示。最低基准只是平移固定10m高度带，也不等于覆盖每个横向位置各自坡脚以上10m；不得不告知用户就改口径。地形起伏不再用单一“z=10等高线x位置”决定统计盒。

网格默认1m×1m×1m。统计质心轨迹，每次试验每格只计一次；逐物理步对相邻快照线段裁剪并进行三维DDA穿越。采用半开格子、最外端封闭，明确线段恰好沿边/角的归属并测试。

正式概率 `hit_trials/N`。正常完成而未进入统计区的试验保留在分母；概率是经过概率，所有格概率之和不要求为1。任一几何失败、数值失败、超时或取消时，整批标记不完整，正式概率留空；不得将失败样本视作未命中，也不得靠悄悄补抽补足N。

同一trial内同k最多64次构造尝试属于采样算法，成功后仍只计一个有效试验；只有耗尽预算或不可恢复错误才记一次最终生成失败。分别输出首次失败率、尝试次数分布和最终失败率。一般批次继续记录其余原定trial，失败槽位不补抽；取消或系统性写盘失败则停止未开始项。

manifest状态区分 `complete/incomplete_failure/cancelled/io_error`，并记录N、正常完成数C、失败/超时数、未开始数。完整批允许的最终失败数为0；中间构造拒绝不使整批自动失效。对不完整批保留诊断计数：若某格在正常完成的C次中命中H次，则全N次经过概率的可能范围为 `[H/N,(H+N-C)/N]`，另列 `probability_lower/upper`；它是未完成结果的确定性范围，不是置信区间，也不是正式概率。禁止把H/C包装成原请求总体的无偏结果。对完成批上下界均等于正式概率。

另输出x=x_end-10处的首次正向穿越截面，网格为y-z；线性插值求截面穿越位置。输出xy/xz投影时，在每次试验内对投影格去重，再累计，禁止直接相加三维体素概率。

### 6.2 预览与后台

- GUI批量要求N>=2。前两次真实推进并绘制，剩余N-2次不播放石头动画，显示进度和失败数。
- 前两次按模拟时间播放，默认1倍速；使用有界快照队列或播放时钟约束，不能让工作线程瞬间算完而窗口只见终态。前两次播放完成后再进入后台阶段；绘制可以跳帧，物理步与统计不能跳过。
- GUI主线程处理窗口与绘制，一个受控数值工作线程顺序完成试验；headless可同步运行同一Trial/BatchRunner。这里的工作线程不是子agent。通过只读快照和命令队列通信，图形API留在主线程，不并行改变随机数消费顺序。
- 预览/相机操作、暂停、窗口大小不得消耗试验随机数。主seed按确定规则派生每个trial_seed；同一运行环境中预览0和2的输入、结果及概率必须一致。
- 批内使用不可变RunConfig，显示本批参数哈希；运行或暂停时可以查看参数，不能应用几何/物性改动。取消或结束后才能应用新设置。默认N=100，seed=20261111。
- 暂停在完整物理步之间生效；取消在生成器的有界迭代和每个物理步检查，不必等待整次60s模拟结束。关闭窗口也走受控取消与清理，不能遗留计算线程或标记结果已完成。
- 状态明确区分Idle、Running、Paused、Cancelling、Completed、Failed；显示已处理/请求数、正常完成数、失败/截断数、当前阶段和本批耗时。后台阶段只刷新进度和汇总，不播放其余N-2条运动。

固定种子协议 `seed_scheme=splitmix64-domains-v1`：所有运算为uint64模2^64；trial_id从1开始，`trial_seed=Mix(master_seed+trial_id-1)`。Mix依次执行 `z=x+0x9E3779B97F4A7C15; z=(z^(z>>30))*0xBF58476D1CE4E5B9; z=(z^(z>>27))*0x94D049BB133111EB; return z^(z>>31)`。种子0是合法固定种子，不隐式替换成时钟。

每trial用分别初始化的mt19937_64流：k流种子 `Mix(trial_seed^0x4B00000000000000)`，物性/初值流 `Mix(trial_seed^0x5000000000000000)`，第a次形状尝试（a=0..63）用 `Mix((trial_seed^0x5300000000000000)+a)`。k只抽一次，失败重试不重抽物性；空闲预览使用独立preview_seed且不消费上述流。固定浮点抽样 `u=(next_uint64>>11)*2^-53`；整数区间用拒绝采样消除取模偏差。物性/初值流顺序固定为x、y、vx、vy、vz、omega_x、omega_y、omega_z、mu、e、Cd、c_rr，每字段消耗一个u，固定值也消耗但忽略该u；密度/r/V为固定配置。记录版本、各域种子和实际数值。

### 6.4 首版界面与交互合同

首版操作流程：选地形场景 → 设置落石/材料/释放条件 → 可选放置刚性挡板 → 单次或批量运行 → 查看轨迹、结果状态和输出目录。界面不展示尚未实现的时间轴或方案对比按钮。

布局为顶部运行栏、左侧参数/对象面板、中央三维视口、底部状态栏；默认窗口1280×720，可调整大小。各参数带单位，非法值在对应控件附近说明原因，失败时保留可改的输入。中文标签与错误信息应可读；图形字体来源与运行路径要记录，使用系统字体时不得擅自打包再分发。

首版采用RenderTexture绘制中央视口，包含深度附件；resize时同步纹理分辨率、投影和拾取尺寸。鼠标扣除视口偏移并转换到纹理实际像素后，用锁定版本的 `GetScreenToWorldRayEx` 或经同等测试的逆矩阵方法构造射线；测试纹理显示的Y翻转与DPI缩放，不能只调整画面而漏改射线。

中文字形从明确的字体文件按标签/错误文字codepoint集合加载，并调用 `GuiSetFont`；路径需宽字符处理时先用本地文件层读字节，再用 `LoadFontFromMemory`。这与可直接使用路径的 `LoadFontEx` 是两种加载入口，按实际锁定版本核对。首版文本编辑限数值/ASCII枚举，不承诺CJK输入法编辑；中文显示限制不能推导为raygui所有版本都不支持UTF-8。配置/导出路径可由命令行或原生文件选择取得。

文件层统一UTF-8配置内容与 `std::filesystem::path` 路径对象；Windows入口用宽字符命令行或显式UTF-8到UTF-16转换，fstream接收path，必要时使用宽字符Windows API。不得未经转换把UTF-8路径交给依赖当前代码页的窄字符fopen。I6使用专门的 `中文目录 with spaces` 测试目录，包括从该目录加载字体/场景和导出CSV，而非只在仓库现有英文路径上试运行。

### 7.1 G：几何测试

- G1：至少5000样本，覆盖k=4..30、r=0.2/2/7/10、支持域下端/中间/上端。先跑`10 20 7 20`的1100样本（每k100个，计入总数），再覆盖小r与V/r³=0.02等边界。每样本检查第4节全部约束，最终失败数须为0；明确首尝试拒绝不等于最终失败，也不能由有限样本0失败断言所有种子必定成功。
- G2：**直接向几何内核输入显式顶点集，不调用generatePolyhedron或其支持域校验**。正四面体、立方体、正八面体的体积、质心及惯量与解析值相对误差<=1e-8；立方体验证共面面三角化不重复计体积。体积/惯量用非零解析量的范数比较，预期零质心改用绝对误差<=1e-8*r。参考体积超出随机采样支持域不影响该单元测试。
- G3：同样直接测几何内核；平移/旋转不改变体积和主惯量，计算惯量均相对质心；缩放仅用于测试，体积按s³、固定密度惯量按s⁵变化，不经过生产采样器的输入范围限制。
- G4：共面点、重复点、NaN、无穷、无效k、越界r/V均给出明确错误；不得崩溃或无限循环。
- G5：Jolt实际碰撞形状也满足第4.3节容差；记录生成耗时中位数/P95及失败数，不捏造耗时指标。

### 7.2 D：物理测试

- D1：关闭阻力、无接触自由落体1s，速度误差<=0.1%，位置误差<=2cm；无外力矩时角动量守恒相对误差<=0.5%。
- D2：对称平面碰撞、无摩擦/阻力：碰前法向速度取2m/s和5m/s，均高于已设置的0.15m/s恢复阈值，实测恢复系数与接触对设置相差<=0.02；偏心碰撞出现正确方向的角动量变化。另测低于阈值时不施加恢复偏置，不用低速测出的近零e否定目标e设置。
- D3：充分静止后连续10s位置漂移<=2mm、姿态漂移<=0.2度。接触总能量不无故爆炸。
- D4：将同一平面三角网格对角线翻转，对照质心路径差<=1cm；不能出现与真实几何无关的接缝弹跳。
- D5：无耗散、含碰撞的验证场景机械能增长<=1%；有耗散时记录损失口径，不将数值损失冒充材料耗能。高速50m/s验证不穿过地形；常规穿透<=max(2mm,0.002r)，若引擎默认容差不满足需调整并复测。
- D6：简单、非混沌场景用dt=0.002/0.001/0.0005、固定4个碰撞子步比较反弹高度或首次碰撞速度，内部间隔对应0.0005/0.00025/0.000125s；粗细相差<=3%。若另测固定内部步长的实验，必须单独命名，不能替代本测试。对复杂翻滚不要求长时轨迹逐点一致，报告步长敏感性。
- D7：执行第5.3节挡板对照；开关和编辑后的碰撞位置与显示一致，越顶/侧边轨迹不受不存在的无限平面拦截；接触材质规则经独立碰撞场景验证。

### 7.3 S：统计与运行测试

- S1：手工构造线段测试跨多格、沿面/边/角、统计区外、进出统计区、往返和同格长驻；计数与解析期望完全一致。
- S2：同批seed、相同编译产物与机器，preview=0/2产生相同trial参数、终止原因和整数网格计数；轨迹数值误差<=1e-8m。不承诺跨不同CPU/编译器的逐位一致。
- S3：N=2恰好两次预览，N=3只有一次后台，N=1000完成计数一致；只在稳定专用场景要求0超时/0失败。一般场景的失败要诚实报告，不以补抽掩盖。
- S4：同k重试后成功仍只占一个有效trial；耗尽重试才算最终生成失败。中途取消、最终生成失败、超时、输出目录不可写、写盘异常分别保留正确状态，正式概率空值。构造N=10/C=8/H=3检查诊断范围为[0.3,0.5]；完整批时范围退化为正式hit/N，所有格概率无需合计为1。
- S5：导出后重载一个试验的顶点、姿态、地形和物性，在相同环境中复现；xy/xz投影计数不得超过N。

种子/地形补充测试：`Mix(0)=0xE220A8397B1DCDAF`；master_seed=20261111的前3个trial_seed应为 `0xFBFC5102A7266B8B,0x0E8F22F720AD06FF,0xF0AC3778B341DAED`，作为协议金标准。人为使一个形状尝试失败，不得改变k、物性或其他trial。对默认参数化地形核对x_end及x=30高程（约34.00858642m），对非整数折点核对网格包含该格线；横坡验证toe_center/toe_min统计域各自的解析期望，越过上游边界产生上游退出而非超时。

### 7.4 I：三维界面验收与选型证据

I1-I3可在P0b静态/预设运动原型上检验；P4接入真实几何/物理后复验受影响项。I4-I5依赖正式核心，不能用原型代替。自动化适合坐标转换、输入分发、状态机和文件往返，遮挡、中文、实际焦点及部署还需真实窗口观察；保存步骤、结果及截图/日志。

- I1 显示：地形、石块和挡板前后遮挡正确；相机穿近裁剪区域无投影爆炸；线框与实体一致，坐标轴/法线/面绕序正确。轨迹和统计轮廓的遮挡策略有说明，不把叠加辅助线的透视显示误作实体遮挡失败。
- I2 相机与拾取：旋转/平移/缩放/俯视/侧视/重置均可操作；验证前后遮挡、空白点选、姿态变化、窗口缩放、侧栏偏移及DPI变化。对已知世界点做投影/反投影，拾取命中距离与对象ID可核验。
- I3 输入与编辑：编辑数值、拖动滑块、展开菜单、拖出控件边界和窗口失焦不会同时移动相机；非法k/r/V/尺寸/NaN等拒绝应用且保留原场景。P4再验收释放点、挡板、配置保存/加载往返及运行中锁定编辑。
- I4 数值独立：同一配置、实际样本和构建，比较headless、preview=2，以及GUI中旋转相机/改变大小/最小化/30或60或不限帧率；trial参数、终止原因、网格整数计数一致，轨迹遵守S2容差。暂停期间模拟时间不增长，恢复不丢物理步。
- I5 批量响应：N=2/3/1000分别核对预览数、进度与结束状态；后台、几何生成和暂停期间均能请求取消，运行中编辑不改变RunConfig哈希。取消与关闭窗口安全收尾，输出遵守S4；实测从输入到状态确认的延迟，按P0b固定的响应门槛验收。
- I6 部署：同一目标电脑从带空格/中文的路径启动，测试字体、中文标签/错误文字、配置读取、可写与不可写导出路径、缺少依赖/字体的明确错误。必须验证release包在非开发终端启动；使用已有编译器，不凭开发终端可运行就认定部署成功。原型阶段先验窗口/字体/路径，P5补全真实导出。
- I7 性能：记录CPU/GPU/驱动/内存、OS、编译模式、依赖版本、窗口与视口大小、DPI、VSync/帧率限制。每种固定负载预热5s、记录30s、重复3次；记录帧时间P50/P95/P99、峰值工作集、输入处理到下一次绘制/状态确认的延迟。后者是软件侧指标，不冒称屏幕实测输入到显示延迟。

### 7.5 批处理吞吐预算（与渲染帧率分开）

首版增加固定 `batch_throughput` 测试配置：x∈[0,20]、y∈[-10,10]的水平面、默认r/V/k范围、无挡板、初速度0、支撑位置释放、e=0、启用摩擦；正常静止判据仍为2s，单次模拟上限10s。该专用场景用于低失败率与吞吐测试，不替代真实坡面60s的截断/失败测试。

P2后先测50次，分别记录生成、积分、统计、写盘时间及实际Update/内部子步数，预测1000次耗时。S3中的N=1000基准以Release、一个数值工作线程、headless、关闭逐步轨迹文件（仍完整统计网格）执行；工程验收目标为总墙钟时间<=15min且0最终失败/0超时，计时包括生成、统计与正常CSV写盘。这是拟定目标，不是当前电脑已测到的性能；若不能满足，先定位/优化，不能靠增大dt、漏计体素或缩短模拟静止判据达标。

真实坡面最坏预算上界为1000×60/0.002×4=1.2亿内部碰撞子步，另加生成/统计/输出开销；实际终止通常早于上限。只用本机测得的对应场景吞吐估算耗时，记录预测与实测偏差，不采用未经实测的“每秒1–3万步”或“必需1–3小时”。N=1000真实坡面可以产生incomplete_failure并保留诊断，不能和稳定专用场景的性能门槛混为一谈。

验收阈值是本任务的目标，不是对当前引擎精度的已验证保证。未通过时先定位单位、拓扑、采样、容差、步长和模型错误，不能直接放宽阈值或把失败改成跳过。确有不可兼容的指标，带失败证据提出变更并等待用户决定。
