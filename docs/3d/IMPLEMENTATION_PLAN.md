## 2. 技术路线与三角建模口径

1. 凸多面体是一个完整实心刚体。先求凸包，再将凸包各面三角化；三角面不能各自建立为动态刚体。
2. k 表示凸包顶点数，不表示面数。闭合凸面三角化且不新增顶点时，检查 `E=3k-6`、`F=2k-4`、欧拉示性数2；共面多边形面也要正确三角化，不重复计算面积/体积。
3. 地形是静态连续三角网格，共享顶点和邻边；相邻同平面三角形的对角线不应变成有物理凸起的边。
4. 体积、质心、惯性张量根据封闭实体积分。质量 `m=rho*V`，默认 rho=2600 kg/m³，取消二维版的固定1m厚度假设。
5. 坐标统一：x沿原下坡方向，y横向，z向上；重力 `(0,0,-9.81)`。所有模块、CSV和显示使用该约定，不能沿用引擎默认Y向上而忘记转换。

依赖决策：使用 Jolt **v5.3.0** 作为首选版本，该版本官方构建说明直接覆盖 VS2022。不要盲用 master 或要求较新工具链的版本。P0解析该标签到实际提交SHA，将SHA及官方来源写入依赖锁定文件；先验证本机可构建再开展主体工作。Jolt采用静态链接，物理引擎与应用编译选项/运行库一致。

使用现有 CMake。制定时已确认 `C:\Users\shell\mingw64\bin\cmake.exe` 可运行，但这只是CMake工具所在目录：生成器必须显式选择 `Visual Studio 17 2022`、x64、v143，不能因此改用MinGW。允许用已有VS附带CMake替代。

Jolt配置采用 `DOUBLE_PRECISION=ON`、`CROSS_PLATFORM_DETERMINISTIC=ON`，以该固定版本的真实CMake选项为准；关闭不需要的Samples、Viewer和性能工具。注意：DOUBLE_PRECISION主要影响位置，不能宣称全部几何、惯量和碰撞计算都变为double。

## 4. 几何输入域与可实现的生成算法

### 4.1 首版支持域

输入 `k_min, k_max, r, V`。默认 `4, 8, 2m, 3m³`。

- `4 <= k_min <= k_max <= 30`。
- `0.2 <= r <= 10` 米。
- 首版数值支持下限 `V/r³ >= 0.02`，不宣称更小体积在数学上不可能。
- 首版体积上限采用可构造参考形状，而非未经证明的真正极值：

  `B4(r) = 8*r³/(9*sqrt(3))`（正四面体）；

  `Bk(r) = (k-2)*r³*sin(2*pi/(k-2))/3`，k>=5（球面两极+赤道正(k-2)边形构成双锥）。

- 要求 `V <= 0.90 * min(Bk(r), k in [k_min,k_max])`。这明确是**首版支持上限**，不是“该k的数学最大体积”；GUI必须这样标注。
- 球心不要求在凸包内部；r是指定生成球半径，不保证是最小包围球半径，也不是质心到最远顶点距离。

必须支持输入 `10 20 7 20`。不得把它改成20m²、修改r、减少抽到的k或用球体替代。

### 4.2 联合约束采样：参考凸包 + 球面连续变形 + 体积求根

下列是待实现和验证的构造方案，不是已经验证的现成程序。

1. 从[k_min,k_max]中均匀抽取整数k，只抽一次；同一试验后续重试都保留这个k。
2. 构造上述参考k顶点球面形状，进行随机切向角扰动并归一化回单位球。逐步缩小扰动幅度，直到参考凸包体积高于目标；0.90容量限制提供构造余量。
3. 随机选择投影轴n，避开所有顶点的反极点。选取正交基(e1,e2,n)，所有单位顶点q_i满足 `1+q_i·n > 0.01`；若候选轴不好就更换轴，最多128次后报告具体失败。
4. 立体投影：`u_i=(q_i·e1,q_i·e2)/(1+q_i·n)`。对全部顶点联合缩放平面投影坐标 `u_i(t)=t*u_i`，t∈[0,1]。
5. 反投影：`q_i(t)=[2t*u_x*e1 + 2t*u_y*e2 + (1-t²|u|²)*n]/(1+t²|u|²)`，最后乘r。此处变化的是角度；没有缩放物理球半径。
6. t=1是参考凸包；t趋于0时所有点趋近n，体积趋于0。凸包体积连续，因此存在中间参数达到目标V。不要宣称全区间单调；用保持异号端点的二分括区求根，不使用未经证明的单调反函数。
7. t=0端点的体积直接按理论极限记为0，不把退化端点送进凸包库。其他t的凸包失败不能被当作“体积为0”，应按数值错误处理。最多80次求根，随后做独立几何检查。
8. 加随机整体旋转；重新验证全部约束。若出现近重复点、不可用的惯量或引擎丢顶点，同一k最多64次更换扰动/投影轴；失败需保留seed、k、r、V及诊断，不能悄悄重抽k或删掉失败样本。

该分布是受约束的形状族，不是所有定体积凸多面体的均匀分布。把 `sampler_version`、参数、试验seed和实际顶点写进结果，以便将来比较采样偏差。

### 4.3 几何与碰撞表示双重校验

规范几何使用double：

- 每个顶点距原球心的半径误差 <= `1e-8*r`。
- 实际体积误差 <= `max(1e-12*r³, 1e-6*V)`。
- 凸包顶点数恰为k；每条无向边恰有两面，方向一致，闭合、凸、无零面积三角形。
- 质心在实体内，惯性张量对称正定。
- 禁止面绕向错误导致正负体积互相抵消；四面体积分参考点优先取实体内部，减少消减误差。

Jolt适配层另行检查：凸包容差不能把k个点简化为更少点；首选不增加圆角半径的凸包设置；实际碰撞外形、质量、质心和惯量与规范几何比较。引擎体积/质量相对偏差 <= `1e-4`，质心偏差 <= `1e-5*r`，惯性张量相对Frobenius范数偏差 <= `1e-3`。超限即失败，不能只验证提交给Jolt之前的数据。

## 5. 三维地形与物理定义

### 5.1 地形

先移植当前参数化坡面函数为h0(x)，保持原始单位和控制点；不include整份二维main文件。首个场景为 `h(x,y)=h0(x)`，横向宽度默认40m。再实现：

- 横坡：`h=h0(x)+tan(beta)*y`，beta默认0度，验证场景5度。
- 沟槽：`h=h0(x)+A*(y/w)^2`，w为半宽，验证场景A=2m。

网格步长默认1m，每个网格四边形固定分为两个三角形；接入静态MeshShape，处理共面内部边。默认无悬挑、洞穴或动态地形。沿x方向必须包含坡面折点，避免1m栅格意外抹平原有台阶。

明确提供世界坐标地形顶点和三角面CSV；观察模式可切换面/线框，显示坡脚统计区和收集截面。

### 5.2 刚体

- 采用完整三维平动和转动，姿态四元数，质心位置与生成球心区分。
- 初始化按多面体最低支撑位置放到地面上方，检测初始穿透；不能使用“质心高度=地面+r”。
- 默认密度2600、摩擦0.45、恢复系数0.45、空气阻力系数1.0。初始自旋默认0，可配置三轴值。
- 逻辑步长0.002s，Jolt内部子步初始4；改变渲染速度只改变单位现实时间推进的固定步数量。
- 明确设置/验证地面与落石材质组合规则，使实际摩擦和恢复系数等于配置要求，而非误用引擎默认组合。
- 空气阻力采用 `F=-0.5*rho_air*Cd*A_proj*|v|*v`；首版 `A_proj=pi*r²` 为明确记录的等效面积近似，不冒充真实姿态相关迎风面积。
- 三维滚动阻力不能直接沿用二维标量omega公式。首版采用明确的现象学模型：存在地面接触时取平均接触法线n，`omega_t=omega-(omega·n)n`；对omega_t施加大小为`c_rr*m*g*r`、反向的力矩。每步按惯性张量限制耗散冲量，保证不反转该转动分量、不增加动能；离地时此项为0。该模型按重量定标，并不声称使用真实冲击法向力，也不包含绕法线扭转阻力；把这些近似写进配置说明和结果。测试c_rr=0无额外耗散，c_rr>0时总转动能不被该项增加。
- 高速模式启用适用的连续碰撞/细分机制，并检测实际穿透，不能只凭引擎开关声称无穿透。

一批地形固定。初始x/y、初速度、摩擦、恢复系数、Cd、c_rr支持固定值或有限均匀区间；两端相同表示固定。r、V、k范围在批内固定，每次重新抽形状。不得继承当前二维批量中写死的释放位置和正态分布却不告知用户。

终止原因必须区分：稳定静止、越过下游边界、离开横向边界、达到时间上限、几何失败、数值失败、用户取消。边界为明确的吸收边界；域外未来轨迹不在本批统计范围。静止要求平动和转动都小，并持续2s；默认上限60s。时间上限是截断状态，不当作正常停止。

### 5.3 首版刚性挡板

挡板为有厚度的静态长方体；配置中心世界坐标、宽/高/厚度、绕z轴方位角、摩擦、恢复系数及启用标志。默认竖直、宽沿横坡方向、厚度沿下坡方向；三个尺寸必须为正。显示网格与碰撞形状共用同一尺寸和变换，配置及结果保存这些实际值。首版只支持一块挡板，在空闲状态通过参数输入放置，不承诺任意空间姿态拖拽。

对挡板增加正撞、偏心撞击、越顶、绕侧边及禁用对照测试：有限尺寸应允许从边缘外通过，不能退化为无限平面。此处模拟刚性接触，结果中的反弹或能量损失不得标成弹性网变形。

## 6. 三维路线统计、展示和输出

### 6.1 统计区

默认统计区：`x∈[x_end-40,x_end]`（截断到有效地形范围）、整个配置y范围、`z∈[z_ref,z_ref+10]`。`z_ref=h(x_end,0)`；这里明确指相对固定坡脚基准的高度，不是每个位置的离地高度。允许配置统计区，三维横坡/沟槽不能继续假定单一的“z=10等高线x位置”。

网格默认1m×1m×1m。统计质心轨迹，每次试验每格只计一次；逐物理步对相邻快照线段裁剪并进行三维DDA穿越。采用半开格子、最外端封闭，明确线段恰好沿边/角的归属并测试。

正式概率 `hit_trials/N`。正常完成而未进入统计区的试验保留在分母；概率是经过概率，所有格概率之和不要求为1。任一几何失败、数值失败、超时或取消时，整批标记不完整，正式概率留空；不得将失败样本视作未命中，也不得靠悄悄补抽补足N。

另输出x=x_end-10处的首次正向穿越截面，网格为y-z；线性插值求截面穿越位置。输出xy/xz投影时，在每次试验内对投影格去重，再累计，禁止直接相加三维体素概率。

### 6.2 预览与后台

- GUI批量要求N>=2。前两次真实推进并绘制，剩余N-2次不播放石头动画，显示进度和失败数。
- 前两次按模拟时间播放，默认1倍速；使用有界快照队列或播放时钟约束，不能让工作线程瞬间算完而窗口只见终态。前两次播放完成后再进入后台阶段；绘制可以跳帧，物理步与统计不能跳过。
- GUI主线程处理窗口与绘制，一个受控数值工作线程顺序完成试验；headless可同步运行同一Trial/BatchRunner。这里的工作线程不是子agent。通过只读快照和命令队列通信，图形API留在主线程，不并行改变随机数消费顺序。
- 预览/相机操作、暂停、窗口大小不得消耗试验随机数。主seed按确定规则派生每个trial_seed；同一运行环境中预览0和2的输入、结果及概率必须一致。
- 批内使用不可变RunConfig，显示本批参数哈希；运行或暂停时可以查看参数，不能应用几何/物性改动。取消或结束后才能应用新设置。默认N=100，seed=20261111。
- 暂停在完整物理步之间生效；取消在生成器的有界迭代和每个物理步检查，不必等待整次60s模拟结束。关闭窗口也走受控取消与清理，不能遗留计算线程或标记结果已完成。
- 状态明确区分Idle、Running、Paused、Cancelling、Completed、Failed；显示已完成/请求数、失败/截断数、当前阶段和本批耗时。后台阶段只刷新进度和汇总，不播放其余N-2条运动。

### 6.3 输出契约

每批独立目录：`results3d/run_<时间>_<pid>_<序号>/`，已有结果不覆盖。记录UTF-8和小数点格式。

| 文件 | 内容 |
| --- | --- |
| `manifest.ini` | 请求参数、实际种子、源码/依赖版本、坐标/单位、采样算法、步长/子步、统计域、挡板配置、RunConfig哈希、状态、耗时 |
| `trials.csv` | trial_id、seed、k、r、请求/实测V、质量、初始条件、终止原因、最终位置/速度/角速度、接触/数值诊断 |
| `shape_vertices.csv`、`shape_faces.csv` | 各试验原生成球坐标系下顶点和三角面、质心变换；足够独立重放 |
| `terrain_vertices.csv`、`terrain_faces.csv` | 完整固定地形及哈希 |

### 6.4 首版界面与交互合同

首版操作流程：选地形场景 → 设置落石/材料/释放条件 → 可选放置刚性挡板 → 单次或批量运行 → 查看轨迹、结果状态和输出目录。界面不展示尚未实现的时间轴或方案对比按钮。

布局为顶部运行栏、左侧参数/对象面板、中央三维视口、底部状态栏；默认窗口1280×720，可调整大小。各参数带单位，非法值在对应控件附近说明原因，失败时保留可改的输入。中文标签与错误信息应可读；图形字体来源与运行路径要记录，使用系统字体时不得擅自打包再分发。

| 操作 | 首版行为与约束 |
| --- | --- |
| 相机 | 在视口内右键拖动环绕目标，中键拖动平移，滚轮缩放；提供俯视、沿y看的x-z侧视、重置按钮。世界Z向上；俯视时选择不与视线平行的up向量，处理极点。显示坐标轴和比例信息 |
| 拾取 | 视口内左键选择落石、地形或挡板，返回最近可见命中并高亮，空白取消选择；拾取需使用物体姿态/平移及正确的视口尺寸、DPI转换，不透过前方地形选后方石块 |
| 参数编辑 | k范围/r/V/N/seed，密度和材料参数，初始位置/速度的固定值或区间，地形类型/宽度/横坡/沟槽、挡板参数；只在应用时校验并更新模型，运行中保持当前批次不变 |
| 设置释放位置 | 进入明确的“设置释放点”模式后点击地形，填入世界x/y；由实际多面体与地形支撑关系计算合法高度，再加非负释放间隙。也可数值编辑x/y及间隙；高度不能只用z+r计算 |
| 放置挡板 | 选中挡板后输入中心位置、宽/高/厚度和方位角，应用后同步显示/碰撞；首版不做自由三轴拖拽或网格雕刻 |
| 运行控制 | 单次、批量、暂停/继续、重置、重新随机；运行中重置需先受控取消。重新随机仅在空闲状态使用独立预览种子，显示/保存该种子；单次运行冻结并使用当前预览样本，正式批次重新从其master seed派生试验 |
| 观察 | 实体/线框切换，轨迹叠加与显示开关，统计域/截面轮廓，质心/速度/角速度；实体用真实深度判断，不能用三角面平均深度排序替代 |
| 配置 | 保存/加载带schema版本的UTF-8 INI场景，包含地形、材料、初始条件、挡板、统计区、种子；加载先完整校验再替换草稿，失败保留当前场景。相机配置与物理配置分开，结果仍以导出的实际几何为准 |

输入优先级见InputRouter。文本编辑、下拉菜单、滑块拖动或模态框活动期间，鼠标/快捷键归控件；按下时取得操作归属，拖出控件区域后也不能突然改成相机旋转。只有视口且未被控件捕获的输入才操纵相机；失焦后释放拖动状态。鼠标射线以实际三维视口而非含侧栏的整窗为基准。

相机和动画插值只影响显示；物理时间、姿态积分、随机生成和体素计数全部在数值层。改变窗口大小、最小化、移动视角、关闭轨迹绘制、设置30/60/不限帧率，都不改变同种子终态与计数。恢复显示时可跳过绘制帧，不能丢弃应计算的物理步。

### 7.1 G：几何测试

- G1：至少5000样本，覆盖k=4..30、r=0.2/2/7/10、支持域下端/中间/上端。每个样本检查第4节全部约束；其中至少1100样本专门覆盖`10 20 7 20`，每个k生成100个。
- G2：正四面体、立方体、正八面体的体积、质心及惯量与解析值相对误差<=1e-8；立方体用于验证共面面合并/三角化，不能重复计体积。
- G3：平移/旋转不改变体积和主惯量；缩放仅用于测试，体积按s³、固定密度惯量按s⁵变化。
- G4：共面点、重复点、NaN、无穷、无效k、越界r/V均给出明确错误；不得崩溃或无限循环。
- G5：Jolt实际碰撞形状也满足第4.3节容差；记录生成耗时中位数/P95及失败数，不捏造耗时指标。

### 7.2 D：物理测试

- D1：关闭阻力、无接触自由落体1s，速度误差<=0.1%，位置误差<=2cm；无外力矩时角动量守恒相对误差<=0.5%。
- D2：对称平面碰撞、无摩擦：实测恢复系数与设置相差<=0.02；偏心碰撞出现正确方向的角动量变化。
- D3：充分静止后连续10s位置漂移<=2mm、姿态漂移<=0.2度。接触总能量不无故爆炸。
- D4：将同一平面三角网格对角线翻转，对照质心路径差<=1cm；不能出现与真实几何无关的接缝弹跳。
- D5：无耗散、含碰撞的验证场景机械能增长<=1%；有耗散时记录损失口径，不将数值损失冒充材料耗能。高速50m/s验证不穿过地形；常规穿透<=max(2mm,0.002r)，若引擎默认容差不满足需调整并复测。
- D6：简单、非混沌场景用dt=0.002/0.001/0.0005比较反弹高度或首次碰撞速度，粗细相差<=3%；对复杂翻滚不要求长时轨迹逐点一致，报告步长敏感性。
- D7：执行第5.3节挡板对照；开关和编辑后的碰撞位置与显示一致，越顶/侧边轨迹不受不存在的无限平面拦截；接触材质规则经独立碰撞场景验证。

### 7.3 S：统计与运行测试

- S1：手工构造线段测试跨多格、沿面/边/角、统计区外、进出统计区、往返和同格长驻；计数与解析期望完全一致。
- S2：同批seed、相同编译产物与机器，preview=0/2产生相同trial参数、终止原因和整数网格计数；轨迹数值误差<=1e-8m。不承诺跨不同CPU/编译器的逐位一致。
- S3：N=2恰好两次预览，N=3只有一次后台，N=1000完成计数一致；只在稳定专用场景要求0超时/0失败。一般场景的失败要诚实报告，不以补抽掩盖。
- S4：中途取消、单次生成失败、模拟超时、输出目录不可写、磁盘写入异常，正式概率保持空值并标记不完整。概率正常时为hit/N，所有格概率无需合计为1。
- S5：导出后重载一个试验的顶点、姿态、地形和物性，在相同环境中复现；xy/xz投影计数不得超过N。

### 7.4 I：三维界面验收与选型证据

I1-I3可在P0b静态/预设运动原型上检验；P4接入真实几何/物理后复验受影响项。I4-I5依赖正式核心，不能用原型代替。自动化适合坐标转换、输入分发、状态机和文件往返，遮挡、中文、实际焦点及部署还需真实窗口观察；保存步骤、结果及截图/日志。

- I1 显示：地形、石块和挡板前后遮挡正确；相机穿近裁剪区域无投影爆炸；线框与实体一致，坐标轴/法线/面绕序正确。轨迹和统计轮廓的遮挡策略有说明，不把叠加辅助线的透视显示误作实体遮挡失败。
- I2 相机与拾取：旋转/平移/缩放/俯视/侧视/重置均可操作；验证前后遮挡、空白点选、姿态变化、窗口缩放、侧栏偏移及DPI变化。对已知世界点做投影/反投影，拾取命中距离与对象ID可核验。
- I3 输入与编辑：编辑数值、拖动滑块、展开菜单、拖出控件边界和窗口失焦不会同时移动相机；非法k/r/V/尺寸/NaN等拒绝应用且保留原场景。P4再验收释放点、挡板、配置保存/加载往返及运行中锁定编辑。
- I4 数值独立：同一配置、实际样本和构建，比较headless、preview=2，以及GUI中旋转相机/改变大小/最小化/30或60或不限帧率；trial参数、终止原因、网格整数计数一致，轨迹遵守S2容差。暂停期间模拟时间不增长，恢复不丢物理步。
- I5 批量响应：N=2/3/1000分别核对预览数、进度与结束状态；后台、几何生成和暂停期间均能请求取消，运行中编辑不改变RunConfig哈希。取消与关闭窗口安全收尾，输出遵守S4；实测从输入到状态确认的延迟，按P0b固定的响应门槛验收。
- I6 部署：同一目标电脑从带空格/中文的路径启动，测试字体、中文标签/错误文字、配置读取、可写与不可写导出路径、缺少依赖/字体的明确错误。必须验证release包在非开发终端启动；使用已有编译器，不凭开发终端可运行就认定部署成功。原型阶段先验窗口/字体/路径，P5补全真实导出。
- I7 性能：记录CPU/GPU/驱动/内存、OS、编译模式、依赖版本、窗口与视口大小、DPI、VSync/帧率限制。每种固定负载预热5s、记录30s、重复3次；记录帧时间P50/P95/P99、峰值工作集、输入处理到下一次绘制/状态确认的延迟。后者是软件侧指标，不冒称屏幕实测输入到显示延迟。

P0b统一负载：1280×720窗口；基准地形120×80个1m网格单元，即19,200个三角形，一个20顶点凸多面体、一块挡板、一条2,000点轨迹；压力场景改为240×160个单元，即76,800个三角形，50条各2,000点轨迹。场景可采用解析坡面，不依赖尚未实现的随机生成器。显示负载不表示承诺能同时物理模拟50块石头。目标电脑无法使用此窗口尺寸时记录实际尺寸，后续在相同条件下比较。

P0b结束时在VALIDATION中填入实测表：`场景/硬件/版本/帧时间P50-P95-P99/峰值内存/输入延迟/通过项/失败项`，据此给出首版支持规模和帧时间、内存、响应门槛；正式接入前固定，不到P5才为通过测试反向改阈值。P5同时复测原型负载与真实运行/后台负载。当前没有这些实测数据，因此本计划不保证帧率、场景上限或开发天数；不得把“使用某库”记成性能验收通过。

验收阈值是本任务的目标，不是对当前引擎精度的已验证保证。未通过时先定位单位、拓扑、采样、容差、步长和模型错误，不能直接放宽阈值或把失败改成跳过。确有不可兼容的指标，带失败证据提出变更并等待用户决定。
