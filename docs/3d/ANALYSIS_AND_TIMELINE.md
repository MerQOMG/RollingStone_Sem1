# 固定障碍、全批热图和只读时间轴

使用仓库现有 VS2022 编译 `build_3d.cmd Release`，运行 `run_3d.cmd --config configs3d/obstacles_heatmap_timeline.ini`。该演示保持 r=2 m、V=7 m³、N=100，释放区为 x∈[10,12]、y∈[−2,2]，主 seed=20261111、障碍 seed=20261112。它是可复现的演示输入，不是材料标定或统计结论。随附预设的碎石默认值已更新；原有地形、滚石和释放参数保持原值。

## 一次完整操作

组合预设已明确使用 `mode=elastic`，支座质量2000kg、刚度500000N/m、阻尼30000N·s/m；界面显示实际位移和截至所选时刻的峰值。当前固定种子前3次未撞板，第4次在约11.87s可看到1.383m瞬时位移，峰值1.384m。前两次预览没撞板时，完成后选择trial 4观看记录；不因此修改采样顺序或伪造预览命中。修复前组合预设遗漏mode而加载成rigid，详见 [修复记录](ELASTIC_DEMO_FIX.md)。

1. 左栏选择“固定障碍”，设置 enabled、数量、seed、区域、尺寸和材料，点击“应用更改”。“生成障碍”显式改变障碍 seed 并重新冻结空闲场景；同 seed 和环境再次启动，布局相同。运行或暂停期间不能应用环境改动。
2. 在“落石 / 批次”设置 N，再点击“批量”。前两次实时预览；第3次起后台顺序计算，每完成一个 trial 加入全轨迹集合，不自动播放后台石块。
3. 点击“分析”。可选择全部轨迹、热图或叠加，调轨迹透明度，切换全路径 xy、首次触板、原坡脚 xy/xz。选中 trial 只高亮，不改变分母。
4. 点击列表或输入 trial 编号，拖下方时间轴，或使用首帧/前一记录帧/播放/后一记录帧/末帧和 0.25、0.5、1、2 倍速。顶部“停算/续算”控制计算，时间轴“暂停回放”只控制显示；计算暂停时仍能看已发布的历史。
5. 在“首触”点击热格，列表只显示该格的正常命中 trial；选中后“跳到首次触碰”显示事件区间内保存的双方姿态和原始接触点。P 编号圆点是世界位置投影标记，可穿过遮挡显示；它不改变实体几何。
6. 保存完成后，点击“打开结果”，选择该目录中的 manifest.ini，或运行 `run_3d.cmd --view-results "结果目录"`。这个入口只读保存数据，不调用 Trial::step 或重新计数。`--replay` 仍是独立的重新积分一致性验证。

前两次可以重新启用“跟随实时”；进入后台后该选项禁用，保持用户选中的 trial 和时间。跟随相机与跟随实时是独立开关。右拖旋转、中拖平移、滚轮缩放；文本编辑和时间轴捕获输入时，相机不处理同一操作。生成失败或尚未记录的条目仍在列表中，时间轴禁用而不显示虚构轨迹。

## 障碍的含义

每批冻结一份 `fixed-box-obstacles-v2` 布局，所有 trial 共用实际几何。默认24块，允许0～500；抽样流独立，不改变落石几何、物性和初态样本。默认 `size_mode=absolute_m`：长/宽0.20～0.50m，露出高0.06～0.18m，总高上限1m；总高另含地形起伏和0.03m埋深。修改滚石 r/V 不会按比例放大碎石；每个碎石 ID 的尺寸和朝向固定抽样，避让重试也不重抽这些值。默认 μ=0.45、e=0.20。

默认 `placement=terrain`、`automatic_region=true` 覆盖整段地形和横向全宽，沿下坡方向分段抽样，边界最多内缩1m。挡板只排除自身附近的保留区，不再截断后面的整个坡面。放置仍检查完整旋转足迹、实际地形三角片高程、释放区、挡板保留区和0.75m间距。每块最多200候选；前100次优先本段，整段被保留区占用时再在全范围尝试；放不满则报错，不少放继续。改变滚石半径若扩大了释放保留区，冲突碎石可以换位置，埋入部分仍按新位置地形计算。

旧场景缺少 `placement` 时保留 v1 走廊、原尺寸单位与随机顺序，旧结果按 manifest 的算法版本和实际几何读取，避免改写历史。需要把旧方案改成新行为时，在“固定障碍”选择 `placement=terrain`、`size_mode=absolute_m`，并填入上述米制尺寸；也可直接加载新版随附预设。显式 `relative_to_r` 仍表示用户选择随 r 缩放。修复与同种子对照见 [碎石分布修复记录](OBSTACLE_DISTRIBUTION_FIX.md)。

障碍是零圆角静态刚体，可拾取 ID/尺寸/材料，碰撞后不移动。材料按对称对象表选择：落石—地形用地面材料，落石—障碍用障碍材料，落石—刚性挡板用挡板材料，落石—弹性挡板 μ 取挡板值、e=0。障碍不与挡板碰撞，也不向弹性支座注入冲量；没有有限位移限位的支座可能穿越障碍，此版本不模拟障碍限制支座的情况。

## 读图时必须保留的分母

| 图层 | 一次 trial 的贡献 | 分母与范围 |
|---|---|---|
| 全路径 xy | 从 t=0 起每物理步质心线段投影穿格，同格最多一次；包括空中段与释放格 | 全地形 x/y，全部高度；正常完成数 C，目标数 N |
| 坡脚 xy/xz | 原统计盒内的逐 trial 去重 | 保留原范围和 toe_center/toe_min 基准，图外不是零概率 |
| 首次触板 | 最早确认子步的全部有效原始点，按容差去重后取局部 y/z 均值，只投一个格 | N 为全批；B 为正常且首触确认，M 为正常且确认未触，C_b=B+M，其余为未知 |

全批完整且文件成功时，经验频率为 H/N，固定0～1色标。计算中、失败或取消时，精确概率为空，仍显示累计下界 H/N 和范围 `[H/N,(H+N−C)/N]`；首触图将 C 换成 C_b。这不是置信区间，不能改用 H/C 冒称总体概率。失败轨迹可见但不并入 H。

首触图另有“条件概率”：全部首触状态已知且 B>0 时为 H_b/B，表示仅在已触板试验中的分布。B=0、禁用挡板、旧结果未记录、取消/未知分别标识；不把它们画成一个通用零值。N=2 也能查看计数与经验频率，界面标 N 和 1/N 分辨率，不保证小样本稳定。默认1m格，保留原始散点；局部宽高图包含正面、背面和边缘，不是受力热图。

## 首触证据和时间精度

确认来源只有保留接触对的几何触碰、普通约束最终压缩法向冲量、实际执行的 CCD 响应。预测候选、接近速度和估算冲量不构成确认；撤销 CCD 不计。默认法向冲量阈值为 max(1e−6 N·s,1e−8×落石质量×1m/s)，几何 slop 沿用原物理参数，没有为热图扩大。

普通约束可能在正间隙时已响应，因此“数值接触”不表示表面严格零间隙。事件保存方法、间隙、最终冲量、阈值、step/substep 和时间上下界。默认 dt=0.002s，每步4子步，典型区间宽0.0005s；不是0.01s绘图采样时刻，更不是实验精确 TOI。缩小 dt 的对照只验证精度与稳定性，不要求不同 dt 轨迹完全一致。更早观测丢失、溢出或阈值歧义会阻止后续命中冒称首次，并进入未知数。

世界触点按同一事件保存的挡板姿态转换为局部坐标；CCD保存查询姿态及fraction。原始点各自保留姿态、来源和确认方法。普通约束的 impulse 是每点最终 lambda；CCD点可能共享同一接触流形响应，标明 `manifold_shared_do_not_sum_points`，禁止将它们简单相加为受力。

事件跳转使用保存的事件姿态，界面不显示未记录的瞬时支座力。普通时间轴位置线性插值，四元数取归一化最短弧 SLERP，动态挡板同一时间对齐；插值仅用于显示，不重新碰撞检测或增加概率。端点不外推，记录时刻返回原值。

## 记录、容量和文件事务

新配置 schema=2，兼容旧配置 schema=1；新结果 schema=3，motion 格式版本1。`history.enabled` 独立于 `output.trajectory_stride`，默认开；stride=0 只关闭普通可读 trajectory.csv 行，首次触板事件和默认二进制历史仍保存。

`history.interval=auto` 在启动前冻结：N<300 为0.01s，否则0.02s；显式间隔向上取整为物理步整数倍，实际值/步数写 manifest 并在启动前显示。保留 t=0、末帧及接触类别变化前后两侧，可能比固定间隔更密，每步最多一帧。记录设置有独立 hash，不改变物理配置 hash。

motion.bin 使用显式小端字段，每帧308B，文件头24B、块头40B，每块至多256帧，带长度、时间/步数范围和 FNV64 校验。索引为所有 N 个 trial 保留条目；只发布已 flush 的完整块。主线程不解析长 CSV 或完整运动文件，受控读取线程按索引加载；历史缓存默认256MiB，`history.cache_mib` 可配，关闭块文件句柄后才发布读取结果。

全局显示预算默认200万顶点（`history.display_vertices`）；按 trial 公平分配，以确定性的最大偏差分段细化保留首尾和转折。显示简化不改变完整历史或逐物理步统计，不淘汰早期 trial。单 trial 显示读取安全上限100万原始帧；当前60s和0.002s物理步上界远小于此值。

实际1000×60s合成历史：显式100Hz为6,001,000帧、1,849,268,024B；auto 50Hz为3,001,000帧、924,788,024B，仅计 motion.bin。动态字段使它大于计划中160B/帧的初步估算；额外接触变化可增加帧数。启动前同时显示固定间隔估计及每物理步一帧的上界，不承诺固定文件大小。

统一结果注册表覆盖25个文件：原文件，加障碍三表、路径热图、首触三表、motion.bin和motion_index.csv。`FILES_COMPLETE.txt` 仅代表文件事务成功；`simulation_complete`、`contact_analysis_complete` 分开。取消可以成功保存有上下界的部分结果。任一写盘/manifest/rename失败保留 `.pending`/`INCOMPLETE.txt`，所有新旧概率文件失效，不能据残留完整标记发布概率。

`--view-results "失败目录.pending" --diagnostic-results` 只浏览校验通过的原始块前缀，正式概率不可用。正常读取遇到坏偏移、截断、校验不符、错误局部触点或缺少新格式必需文件会明确报错。读取中的块错误会停播并标记概率失效。

旧结果按实际 CSV 帧浏览；缺历史或旧 stride=0 禁用时间轴。没有首触记录就显示“未记录”，不从质心或最终 touched 反推。缺少动态挡板历史时隐藏该运动部件并提示；刚性挡板仍可使用保存的静态配置。只读实际形状容量为10万顶点/20万面，独立于生产采样 k≤100；仍检查闭合性、面索引和实际质量几何，不跳过损坏校验。

## 复验入口

```powershell
./test_3d.cmd
python scripts3d/benchmark_analysis.py p1 results3d/analysis_p1
python scripts3d/benchmark_analysis.py p2 results3d/analysis_p2
./run_3d.cmd --view-results "完整结果目录" --benchmark --fps 0 --evidence results3d/analysis_gui_perf
```

P1/P2顺序执行，测量时不并行构建、测试或其他 GUI 基准。P1包含全部1000条轨迹读回，不能用合成档案代替真实碰撞验证。P2以当前同一构建的障碍关闭/历史关闭为基线，测四种组合的100次真实试验。数值观测适配审计见 [DEPENDENCIES](DEPENDENCIES.md)，完整验收及限制见 [F0–F5记录](OBSTACLES_HEATMAP_TIMELINE_VALIDATION.md)。
