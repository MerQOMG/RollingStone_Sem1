Noto Sans SC (SIL Open Font License 1.1) - interface font of RollingStone3D.

NotoSansSC-Regular.ttf  (weight 400)
NotoSansSC-Bold.ttf     (weight 700)

Source: https://github.com/notofonts/noto-cjk (Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf).
Both files were produced from that variable font by fixing the weight axis (fontTools instancer) and
reducing it to the GB2312 Chinese characters plus Latin letters, digits, punctuation and the symbols used by the
interface, to keep the program small. The glyph designs are unchanged. The license text is in licenses/NotoSansSC-OFL.txt.
If a character is missing from the subset the program falls back to a Windows system font.
